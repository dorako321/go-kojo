# sl

sl prints a small original ASCII art steam locomotive to standard output.

## Install

```
go install github.com/dorako321/sl@latest
```

## Usage

```
sl prints a small original ASCII art steam locomotive to standard output.

Usage:
  sl

Examples:
  sl
  sl -version
  sl -h

Flags:
  -version
    	print version and exit
```

```
$ sl
     (  )
    (  )
  ___    _______
 |   |__|  _  _ |
 |__________________|
  (o)(o)(o)(o)(o)
```

```
$ echo hello | sl
     (  )
    (  )
  ___    _______
 |   |__|  _  _ |
 |__________________|
  (o)(o)(o)(o)(o)
```
